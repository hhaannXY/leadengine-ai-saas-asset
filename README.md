# LeadEngine AI

> Enterprise-grade AI-powered B2B Prospecting & Website Audit Platform

**Status:** Available for Acquisition

LeadEngine AI is a production-oriented SaaS platform designed for AI-powered lead generation, website analysis, and multi-tenant B2B workflows.

This public repository exists solely as a technical overview for qualified buyers.

The complete functional source code is maintained in a private repository and is transferred as part of the acquisition.
